## 三、议题 4a 实施记录：移除「⚠ 需要确认 · SysML 产物入库」卡片

**为什么是移除而不是保留**（判定依据来自代码本身，非主观）：

1. 该能力**已不存在**：`14-sysml.js` 文件顶部注释即写明「旧单版本『入库』入口已移除：AI 建模代码不再直接入库，归档动作收敛为工程级一次性操作」。
2. 卡内按钮是**伪闸门**：`approvalDecision()` 只做两件事 —— 写 `localStorage('sysmlAp')` + 弹提示「请去版本历史点『📦 工程入库』」，**没有任何真实入库动作**；「驳回」同样无副作用。
3. 它**误导用户**：常驻琥珀色审批卡会让人以为"不在此确认就无法入库"，而真实入口（图谱工作区 · 版本历史 →「📦 工程入库」、文件预览面板）与之无关。

**改动清单**

| 文件 | 改动 |
|---|---|
| `static/js/mods/05-markdown.js:298–304` | 删除 `html += sysmlApprovalCardHtml(m, cd);` 调用，改为保留说明注释 |
| `static/js/mods/14-sysml.js` | 删除 `sysmlApprovalCardHtml()` / `approvalDecision()` / `_sysmlApGet()` / `_sysmlApSet()`（共约 45 行），留下移除原因注释 |
| `static/index.html` | 删除仅服务该卡的 `.approval-card` 样式块（11 行，含 `.approved` / `.rejected` 变体），避免留下死 CSS |

**验证**：DOM 中 `.approval-card` 节点数 **0**；`sysmlApprovalCardHtml` / `approvalDecision` 全局已 undefined；样式表中 `approval-card` 规则 **0 条**；消息流文案「需要确认 · SysML 产物入库」已不存在。

## 四、议题 4b 实施记录：归一确认（人在回路）支持全屏查看 / 恢复

**改动**

| 位置 | 改动 |
|---|---|
| `07-norm.js` 状态 | 新增 `fullscreen:false`、`_nrFullAnchor:null` |
| `07-norm.js` 卡头 | 新增「⛶ 全屏 / ⤡ 恢复」按钮（`event.stopPropagation()`，不触发卡头折叠） |
| `07-norm.js` 新增 `_nrToggleFullscreen()` | 进入全屏时把宿主搬到 `<body>` 直下并记原锚点；退出时原位归还（锚点失效则摘除宿主）；Esc 键（capture）可恢复 |
| `03-chat.js:selectConv` | 切换会话前显式退出全屏，避免会话重渲染后留下悬空覆盖层 |
| `app.css` | `.nr-inline.nr-full` 覆盖层样式（`fixed/inset:0/z-index:1300`）+ `body.nr-full-lock` 锁背景滚动 + 高度解禁 |

**实测踩到的两个坑（已修）**

1. **`max-height` 是内联样式**：`#nr-rows`（340px）与 `#nr-v2code`（280px）由 `07-norm.js` 内联写死，样式表规则被内联优先级压过 → 全屏后仍是 340px。**修法**：覆盖规则加 `!important`。
2. **`.msg` 带 `content-visibility` 会成为 `fixed` 的包含块**：经祖先链诊断（`DIV#msg-2804 → content-visibility`）确认，仅靠 CSS 无法真正铺满视口——覆盖层被限制在消息框内。**修法**：全屏时把宿主搬到 `<body>`，退出时按锚点归位。

**验证（真实 20 行归一清单）**

| 断言 | 结果 |
|---|---|
| 进入全屏：宿主类名 / 定位 | `nr-inline nr-full` / `position:fixed`，`inset:0/0` |
| 全屏层实际矩形 | **0,0 → 1600×900（真正铺满视口）** |
| `#nr-rows` 高度 | 340px（封顶） → **590px（全屏实测）**，`max-height:none` |
| 背景滚动锁 | `body.nr-full-lock = true` |
| 按钮文案 | 全屏时「⤡ 恢复」 |
| Esc 恢复 | 类名回 `nr-inline`、`position:static`、`max-height:340px`、`nr-full-lock=false` |
| 决策状态 | 全屏前后 `window._nrState.decisions` 全程保留（DOM 重绘不销毁状态） |
| 页面错误 | 0 条 |
