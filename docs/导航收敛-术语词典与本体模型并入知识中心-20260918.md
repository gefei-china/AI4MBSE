### 1.3 顺带修掉一个串味缺陷（术语词典 ↔ 本体模型）
旧实现按 `window._kbCtx` 的**残留值**判断进哪个视图：
```js
// 15-kb.js（旧）
const _termsEntry = (window._kbCtx==='terms');
if(!_termsEntry) window._kbCtx = 'model';
```
→ 只要上次停在术语词典，之后**任何**入口（深链 `go('kb','kb-c')`、侧栏「本体模型」、角色快捷）都会再次进术语视图。

新实现改为「**显式子态**」：
```js
// 15-kb.js（新）—— 置于 loadKBTab 开头，必须先于 chip 高亮落定语境
if(id === 'kb-c'){
  window._kbCtx = (window._kbCtxTerms === true) ? 'terms' : 'model';
  window._kbCtxTerms = false;   // 一次性消费，随即复位
}
```
只有两个入口会置 `_kbCtxTerms=true`：知识中心 Tab「📖 术语词典」、KBar「术语词典」。
其余入口（深链 / 侧栏 / 角色快捷）**一律落在本体模型**。

### 1.4 同步清理的失效逻辑
- `02-shell.js` `go()` 与 `tab()` 中「两个导航项按 `_kbCtx` 区分高亮」的分支 → 删除；知识域高亮统一为 `nav-kbhub`（`kb-d`/`kb-e`/`kb-c` 三个 Tab 全部点亮它，术语词典态同样点亮）。
- `02-shell.js` 主导航 click 监听里为 `nav-glossary2` 写 `_kbCtx` 的分支 → 删除。
- 面包屑：`本体模型`（kb-c 常态）/ `术语词典`（terms 态）由 `pageCrumb()` + `showOntTerms()` 分别产生，未变。
