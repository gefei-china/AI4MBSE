## 4. 优化方案

### P0 — 必做（改动小、收益直接、零新依赖）

#### P0-1 图谱样式单一真源（白底蓝框蓝线语义不变）

- **现状**：四处硬编码，SVG 与 Cytoscape 同一类型颜色可能不一致；`tokens.css` 变量 Cytoscape 读不到。
- **目标**：改一处全局生效；主画布恒 `#fff`。
- **做法**：`24-graph.js` 顶部新增 `GRAPH_TOKENS`，启动时用 `getComputedStyle(document.documentElement).getPropertyValue('--color-primary')` 取实值缓存（Cytoscape 必须实值，不能 `var()`）；`graphColor()` / SVM 样式表 / Cytoscape style / SVG 节点边统一引用；影响图红/橙/灰语义色保留，仅改为引用同一 token。
- **收益**：消除跨视图色差；换品牌色只改一处。
- **风险**：缓存时机须在 CSS 加载后；四文件改动需截图回归。

#### P0-2 三套画布统一邻域高亮

- **现状**：主 SVG 完整（hover 淡出+光晕+蚂蚁线），影响图有 `impactFocusNode`，SysML 仅 `:selected` 粗蓝框。
- **目标**：任一画布选中/悬停节点 → 高亮 1-hop 闭邻域、其余压暗、边按真实方向流动；点空白统一取消。
- **做法**：抽公共 `applyGraphFocus(cyOrSvg, id)`；Cytoscape 用 `closedNeighborhood()` + `.dimmed/.focus-hi`（复用 `09-impact.js:89-90,152-157`），SVG 复用 `gvNodeHover/gvClearHover`；在 `svmRenderCytoscape()` 的 `cy.on('tap','node')`、图例点击 `25-graphview.js:743-749`、实体树点击 `26-grapheditor.js:111-117` 统一挂接。
- **收益**：跨视图认知负担下降，方向表达一致。
- **风险**：tap 与 mousedown 冒泡；只读态（release 分支 `26-grapheditor.js:736-740`）仍须可高亮。

#### P0-3 修复拖拽整图重建（性能最优先）

- **现状**：`graphSvgMove()` `26-grapheditor.js:829` 每次 mousemove 调 `renderGraph()`，后者 `:882` 用 `el.innerHTML=s` 重建全部节点边。
- **目标**：拖拽/平移 60fps，落位后再持久化。
- **做法**：拆 `buildGraphSvg()`（结构变更全量）与 `updateGraphTransform()`（仅更新 `<g id="gv-inner">` transform 与节点 `<g transform>`）；拖拽中只改 `graphState.nodes[i].x/y` 并直接写 DOM，`mouseup` 后再 `renderGraph()`+`saveNodePos()`。保留 `gvApplyView(true)` 跟手路径 `:595-620`。
- **收益**：大图拖拽不卡；与已有 `__cyIdleMount` 优化（`25-graphview.js:499-511`、`09-impact.js:51-53`）形成闭环。
- **风险**：DOM 与 `graphState` 同步；选中态仍由 `renderGraph()` 统一刷新。

#### P0-4 统一工具栏文案与可交互提示

- **现状**：`25-graphview.js:793` 与 `09-impact.js:245` 两套提示；筛选 `:761`、连线 `:792` 各自为政。
- **目标**：三画布统一一行状态提示 + 固定 FAB（缩放/适配/图例/minimap）。
- **做法**：抽 `gvHintBar(mode)`，三处复用；对齐 `title` 文案；预埋「Shift+拖拽框选」提示。
- **收益**：交互可发现性提升；零依赖。
- **风险**：极低，纯文案与 DOM 微调。

### P1 — 中等成本，显著提升专业度

#### P1-1 框选（矩形/Lasso）多选

- **现状**：`25-graphview.js:242` 注释声称支持，实际无实现；空白按下一律当平移（`26-grapheditor.js:812-821`）。
- **做法**：`graphSvgDown` 增加 `ev.shiftKey` 分支 → 半透明蓝框 `<rect>`（stroke `#185FA5`、fill `rgba(24,95,165,.10)`），move 更新，up 屏幕坐标命中测试写 `graphState.multiSel`；Cytoscape 用 `cy.on('boxselect')`。
- **收益**：补齐行业标配（Reagraph/Gephi），为批量操作打底。
- **风险**：修饰键冲突 → 强制 Shift；多选与单选 `graphState.sel` 定义优先级。

#### P1-2 双击节点展开/收起 1-hop

- **现状**：只有骨架 L1→L2→L3 全量下钻，无单节点展开。
- **做法**：`graphNodeDown()` `26-grapheditor.js:706-743` 加 `dblclick`，维护 `graphState.expanded Set`；展开时从 `graphState.all` 取邻居（沿用 L3 的 60 上限保护），用 headless dagre/cose `24-graph.js:307-331` 只重排局部；折叠回原状态；节点带 `+N` 虚线徽标（复用 `_skel` 样式 `:871-872`）。
- **收益**：从「全量/骨架」二值探索变为渐进式探索，减少首屏节点数。
- **风险**：展开坐标与已保存 `graph_x/graph_y` 冲突；与骨架模式互斥提示。

#### P1-3 布局参数可调 + 增量布局

- **现状**：仅 3 个布局下拉，cose 参数写死，每次全量重排。
- **做法**：筛选下拉加「节点间距/斥力/迭代次数」滑杆写 `graphState.view.layoutOpts`，传 `gvLayoutWith()`；增量模式记录 dirty 节点集，仅对 dirty 子图跑布局，其余坐标锁定。硬上限（斥力 10000–60000、迭代 100–800）。
- **收益**：密集约束图重叠减少，调参不改代码。
- **风险**：极端参数导致重叠/飞出。

#### P1-4 路径高亮工具（Path Finder）

- **现状**：影响图有传播路径表 `09-impact.js:971-977`，主图/SysML 图无任意两点路径查找。
- **做法**：在连线模式外新增「路径」模式，复用 `gvLinkMode` 状态机 `26-grapheditor.js:745-811` 的两次点选；对 `graphState.edges` 做 BFS，路径边加 `.gv-flow-out`、节点加 `.gv-hov-ring`，其余 `.gv-hov-dim`；Esc 退出。
- **收益**：需求追溯、影响链定位从「肉眼找」变「一键高亮」。
- **风险**：多重边/环歧义 → 明确「最短跳数 + 同层按关系类型字典序」口径。

#### P1-5 SysML 视图标签密度治理

- **现状**：Cytoscape 边标签 `text-rotation:'autorotate'`、`text-background-opacity:0.7` `25-graphview.js:453-454`，大图互相遮挡。
- **做法**：监听 `cy.on('zoom')`，`zoom<0.6` 隐边标签、`<0.4` 隐节点副标题；用 `min-zoomed-font-size` 或 class 切换；SVG 回退按 `graphState.vp.scale` 控 `font-size`。
- **收益**：BDD/PKG 大图可读性明显提升。
- **风险**：阈值需中文实测；信息暂时隐藏须在图例提示。

### P2 — 中长期

- **P2-1 社区/模块聚类着色**：纯 JS 连通分量或轻量标签传播（不引新库），结果写 `n._community`，低饱和 12 色带；与类型色互斥，默认仍白底蓝框。参考 Gephi Modularity。
> **实施备注（2026-11-28）**：标签传播实测会把**整张连通图塌成 1 个社区**（两团+一桥的用例）——这恰好是「模块结构」要解决的问题，故实现改用**模块度局部移动（Louvain phase-1，Gephi Modularity 同类）**，连通分量保留为 `method="components"` 退化模式；确定性由「节点 id 字典序 + 平票取最小标签」保证。
>
> **P2-2 实施备注**：除 view/vp/sk 外**额外存了节点坐标**（≤400 节点）。理由：力导向布局每次重算坐标都不同，只存 vp 会出现「恢复了缩放却对着另一张图」。恢复时坐标齐全则精确复原，缺失则重排并如实标记 `exact=false`。
>
> **P2-3 实施备注**：既有 JSON/GraphML/SysML 导出的是**分支全量数据**，与画布所见无关；新增的「当前视野 SVG/PNG」导出的是**画面上这一张**（含筛选/折叠/高亮/缩放），两者在下拉里分组标注。

### 后续迭代（2026-11-28）：节点尺寸与选中聚焦

- **背景**：米爸反馈「节点有点小，选择节点后被选节点更大些，且自动移到视图中间」。
- **根因不是半径**：61 节点时 `svgH` 被算成 1280（旧公式「每 4 个节点一排、每排 80px」与画布宽度无关），
  而视口只有 ~848×619 ⇒ `gvFitView` 只能压到 `scale≈0.59` ⇒ 半径 13 的圆屏幕直径仅 ~15px。
  只调半径会被 fit 再压回去，所以三处必须同时改：
  1. 半径 13–26 → **17–33**（`nodeBaseR` / `nodeDegStep` / `nodeDegCap`，全部进 token）；
  2. `svgH` 改为**按密度摊派**（每节点预留 `(nodeCollideMinD×1.6)²` 面积，再摊到画布宽度）⇒ 61 节点 = 560 高；
  3. 碰撞最小距 44/46 → `nodeCollideMinD=56`，并把驱动轮数 6→12（节点变大后单轮推开量相对变小）。
  实测：屏幕直径 15.4px → **45.2px**，`scale` 0.59 → **1.08**。
- **选中放大**：`nodeSelScale=1.32` 作用在半径上（不是只加粗描边）；半径公式抽成 `gvNodeRadius(n, deg, sel)`
  单一实现 —— 内联表达式只能靠测试复刻断言，而复刻不随源码变（第一版变异「去掉选中放大」后判据仍绿）。
- **选中居中 + 缩放下限**：`gvRevealNode(id)` 同时做「居中」与「缩放拉到 `nodeFocusScale=0.9`」。
  只居中不够 —— `scale=0.59` 时居中后屏幕直径仍不足 25px，等于没解决「看不清」。
  语义是**只放大不缩小**（`Math.max(当前, 下限)`），用户已放大到 1.8 时点节点不会被缩回去。
- **时机必须在 mouseup**：`mousedown` 时 `graphState.drag` 的 `ox/oy` 已按当时的 vp 算好，
  此刻改 vp 会让紧随其后的 `mousemove` 按新 vp 反算 ⇒ 节点跳飞（真机实测过 −1128px 飞出视口）。
  因此 `graphNodeDown` 记下按下坐标 `sx0/sy0`，`graphSvgUp` 用「位移 ≤2px」区分单击与拖拽：
  单击 ⇒ 居中且**不写库**（原实现每次单击都发一次 PUT）；拖拽 ⇒ 写库且**不居中**（不抢用户刚摆好的位置）。
- **顺带修掉的真实缺陷**：`graphCollide` 对完全重合的两个节点推不动 —— 原式 `||0.1` 只兜住了分母，
  分子 `dx=0 ⇒ 位移恒为 0`。真机出现过中心距 2.3px（两个圆完全叠住、其中一个根本点不到）。
  修法要把**方向**与**推力**分开：方向在重合时按索引给确定值（黄金角，不用随机数），
  推力仍按真实距离算 —— 若把「定方向用的 0.5」当真实距离参与推力，会少推一半、只到 `minD−0.5`。
- 门禁：`tools/verify/verify_graph_p3_focus.py`（46 项，含 5 组变异）；真机 16 项。

- **P2-2 视角/场景保存**：序列化 `graphState.view/vp/sk` 到 localStorage（仅本机），工具栏加下拉；视角绑定分支名，切分支提示。参考 Bloom Perspective/Scene。
- **P2-3 导出当前视图 SVG/PNG**：序列化 `#gv-svg` 补 `xmlns` + 内联字体栈；PNG 用原生 canvas + Blob URL（注意中文字体栈、大图进度提示）。现有 GraphML 已可喂 Gephi。
- **P2-4 键盘可达性**：节点 `<g>` 加 `tabindex/role/aria-label`，方向键邻域移动、Enter 详情、Esc 取消；须与 P0-3 的 DOM 差分一起做（`innerHTML` 重建会丢焦点）。

## 6. 实施顺序建议

1. **P0-3 性能**先做（独立、见效快、风险可控）；
2. **P0-1 样式单一真源**（为 P0-2/P1 打底）；
3. **P0-2 交互统一** + **P0-4 文案**；
4. 按用户反馈优先级挑 P1-1/P1-2/P1-4；
5. P2 作为后续迭代，不阻塞主线。

每项落地须同步：`tools/verify/verify_graph_*.js` 类门禁的精确锚点、`verify_hil_mutation.js` 的模板行锚点、`tools/gates_manifest.json` 登记，以及 `static/vendor/` 保持零外部依赖。
