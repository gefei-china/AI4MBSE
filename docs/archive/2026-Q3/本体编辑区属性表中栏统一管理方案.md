# 本体编辑区 · 属性表中栏统一管理方案（四轮调整第 4 条，先方案后实施）

> 2026-09-02 · 状态：待米爸拍板后实施
> 关联：本体编辑区 WebProtege 对齐改造清单 P0~P2（已全部落地）

## 1. 现状与问题

| 项 | 现状 | 问题 |
|---|---|---|
| 属性表（寄生属性）编辑 | 编辑态中栏「✏️ 属性表」/「✏️ 编辑」→ **右侧滑窗表单**（ot-props-section 动态行） | 违背既定契约「编辑⇄图谱⇄OWL 均在中栏内联」；滑窗遮挡左栏树，编辑时失去上下文；两处入口（实体侧 properties / 关系侧 cons.attributes）行为重复 |
| 数据格式 | `properties: {k: {note, type, required}}`（兼容旧 `{k: 说明}`）；关系侧 `constraints.attributes` 同构 | 兼容读取已收敛，无需迁移 |
| 保存通道 | 滑窗整表单提交 → `PUT /api/knowledge/ontology/types/{id}` | 接口可直接复用，无后端改动 |

## 2. 目标

1. 属性表的**查看与编辑全部收进中栏**（编辑态 Description 内），不再打开滑窗；
2. 与 WebProtégé 行内编辑体验对齐：表格化、行内编辑、即时保存；
3. 关系类型（对象属性）的属性表（constraints.attributes）走同一组件；
4. 左栏树 / 右栏注释·引用 不随动（契约不变）。

## 3. 方案对比

| 方案 | 说明 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. Description 内联表格（推荐）** | 「属性表」section 从只读摘要升级为**可编辑表格**（列：属性名 / 说明 / 类型 / 必填），行尾 ✕ 删除、底部＋ 添加行 | 与 Protégé 行内编辑一致；零遮挡；契约完全对齐 | 中栏纵向变长（表格区限高+滚动可控） | ✅ 采用 |
| B. 中栏底部抽屉 | 点「属性表」在中栏底部展开编辑抽屉，完成收起 | 不改动 Description 布局 | 多一层开关状态；与 OWL/RDF 折叠条抢占底部空间 | 兜底 |
| C. 维持滑窗 | 现状 | 无改动 | 违背契约，体验割裂 | 弃 |

## 4. 方案 A 交互设计

### 4.1 表格结构（renderOntDesc 内 `ontPropTable(t)` 组件）

```
属性表（寄生属性 · N 项）
┌──────────┬──────────────────┬───────────┬──────┬─────┐
│ 属性名    │ 说明              │ 类型 ▾     │ 必填 ☐ │ ✕  │
│ EIRP     │ 等效全向辐射功率   │ decimal ▾ │ ☑    │ ✕  │
└──────────┴──────────────────┴───────────┴──────┴─────┘
[＋ 添加属性]                                   [✔ 保存] [✕ 取消]
```

- **查看态**（默认）：表格只读，行 hover 显 ✏（该行进入编辑）——先只读后编辑，避免误触；
- **编辑态**：整表进入编辑（与滑窗 prefillPropRows 行结构一致，迁移成本低）；「✔ 保存」一次性 PUT；有改动时「取消」弹确认；
- 类型下拉：`string / decimal / bool / date / text`（沿用 XSD 映射）；
- 必填勾选：保存时联动 `constraints.required`（勾选项追加进 required 列表，去重）。

### 4.2 校验规则（保存前）

1. 属性名非空、行内唯一（重复行红框标出并 toast）；
2. 属性名建议走术语词典谓词规范化（软校验：命中词典时提示，不阻断）；
3. 类型必选（默认 string）。

### 4.3 保存与联动

- 复用 `PUT /api/knowledge/ontology/types/{id}`：body 全量（name/type_kind/properties/constraints/…），成功后 `loadOntology()` 重载 + `ont-flash`「已写回」提示（复用现有反馈机制）；
- 变更历史自动记录（后端已有 INSERT INTO ontology_change_logs）；
- IRI / 名称等其余字段**不在本表格内**（仍由中栏头部与既有编辑通道负责，职责不混）。

### 4.4 关系类型（对象属性）属性表

- 同一组件渲染 `constraints.attributes`，保存时合并写回 constraints；
- 中栏 Description 关系分支新增「属性表」section（当前只有实体侧有）。

### 4.5 明确不做（本期）

- 实例层（个体）的属性值编辑——属实例图谱页职责；
- 属性表批量导入/导出（后续可挂 CSV）；
- 属性级 IRI。
