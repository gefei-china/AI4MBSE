## 2. 需求一：AI 输出可折叠 + 集中阅读最终结论

### 2.1 目标

让 AI 消息呈现为「**结论速览（默认展开） → 折叠过程区（默认收起）**」的两段式结构，**评审交付场景 70% 时间花在读结论而非爬过程**。

### 2.2 方案设计

#### 2.2.1 消息渲染结构（前端 `06-cards.js`）

```
┌────────────────────────────────────────────────────────┐
│  [💡 结论速览] ← 始终展示（可点 "▽" 折叠）              │
│  ────────────────────────────────────────              │
│  • 提取到 3 个需求条目、1 个冲突                       │
│  • 已生成 SysML V2 代码 124 行（通过语法校验）         │
│  • [查看产物卡片] [跳转到图谱] [复制结论]              │
├────────────────────────────────────────────────────────┤
│  [▼ 展开推理过程（共 8 步，耗时 12.3s）] ← 默认折叠     │
│   └─ 折叠后展开 → 现 proc_blocks 四段（思考/Agent/子任务/工具）│
│   └─ "全部折叠/全部展开" 联动按钮                      │
└────────────────────────────────────────────────────────┘
```

#### 2.2.2 「结论速览」数据契约

后端 `/api/conversations/{id}/messages` 在 AI 消息的 `card_data` JSON 中新增 `summary` 字段（与现有 `plan/tools/reasoning` 同级）：

```json
{
  "summary": {
    "headline": "提取 3 条需求 + 1 处冲突",          // 一句话结论（≤30字）
    "bullets": [                                      // 关键要点 3-5 条
      "需求条目：REQ-001/002/003（含来源追溯）",
      "冲突检测：REQ-001 与 REQ-002 时序约束矛盾",
      "已生成 SysML V2 代码 124 行，通过语法校验"
    ],
    "artifacts": [                                     // 关联产物跳转
      {"kind": "sysml", "label": "需求模型 v1", "ref": "sysml_versions:42"},
      {"kind": "graph", "label": "图谱视图", "ref": "/graph?ids=..."}
    ],
    "stats": {                                        // 关键指标
      "tokens": 2456,
      "elapsed_ms": 12340,
      "tool_calls": 5,
      "subtasks": "6/6"
    }
  }
}
```

**生成时机**：在 agent.execute_stream 的 `done` 事件落地前，调用一个轻量 LLM（≤256 tokens）抽取上述摘要；**失败兜底**：用规则法从 `plan + tools` 中提取（首条子任务标题、工具调用次数、ok 数）。

## 3. 需求二：文件生命周期管理

### 3.1 目标

将「上传 → 解析 → 分块 → 入库 → 候选抽取 → 评审 → 正式入库 → 废弃 → 归档」9 个阶段抽象为**6 态状态机**，覆盖 FR-KG-8「原始切片/候选/已入库/已废弃」+ ArcR-5 全链路管理要求。

### 3.2 状态机

```
                  ┌──── reindex / retry (回归上传)
                  ↓
   uploaded ─→ parsing ─→ parsing_failed ─→ reupload ─┐
                  ↓ ok                              │
                chunking ─→ embedding ─→ stored (向量层)
                  ↓ ok
                extracted ─→ review_pending ─→ review_passed ─→ committed (正式入图谱)
                                              ↘ review_rejected ─→ archived
                                                                  
   committed ─→ deprecated (软删) ─→ archived (硬挪到只读分区)
                                     ↘ restored (撤销废弃)
```

**6 个核心状态**：

| 状态 | 含义 | 向量库命中 | 图谱可见 |
|---|---|---|---|
| `uploaded` | 刚落盘未解析 | ✗ | ✗ |
| `parsing` | 解析/分块/向量化中 | ✗ | ✗ |
| `stored` | 向量化完成（向量层就绪） | ✓（默认可见） | ✗（待评审） |
| `committed` | 经评审合并入图谱（发布版） | ✓ | ✓ |
| `deprecated` | 软删除（保留审计） | ✗（过滤） | ✗（过滤） |
| `archived` | 归档（只读分区，紧急恢复用） | ✗ | ✗ |

> **P1 候选态**：`extracted / review_pending / review_passed` 三态细分（如启用 v2g 候选评审），本期可在 `pipeline_detail` JSON 标记，**不强制升级为列**。

### 3.4 API 设计

| 方法 | 路径 | 用途 | 权限 |
|---|---|---|---|
| POST | `/api/documents/{id}/deprecate` | 软删除（body: `{reason}`） | `doc:write` |
| POST | `/api/documents/{id}/restore` | 撤销废弃（仅 24h 内可撤销，超期需管理员） | `doc:write` |
| POST | `/api/documents/{id}/archive` | 归档（只读分区，紧急恢复用） | `doc:admin` |
| GET | `/api/documents?lifecycle_status=deprecated` | 列表按状态过滤 | `doc:read` |
| GET | `/api/documents/{id}/lifecycle` | 生命周期时间线（来源 + 状态变迁） | `doc:read` |
| POST | `/api/documents/batch-deprecate` | 批量废弃（body: `{ids:[], reason}`） | `doc:write` |

**路由实现（伪代码）**：

```python
# routers/meta.py
@router.post("/api/documents/{doc_id}/deprecate")
def deprecate_document(doc_id: int, body: dict, conn=..., user=...):
    """软删除：写 lifecycle_status='deprecated' + 落审计日志。
    
    联动：document_chunks.lifecycle_status 同步置 deprecated（向量层过滤）；
    不级联删除关联 entities/relations（保留溯源），entities 由 status='deprecated' 隔离。
    """
    actor = audit_user(user)
    reason = (body.get("reason") or "").strip()[:500]
    if not reason:
        return JSONResponse({"error": "废弃理由不能为空（审计要求）"}, 400)
    
    cur = conn.execute("SELECT lifecycle_status FROM documents WHERE id=?", (doc_id,)).fetchone()
    if not cur: return JSONResponse({"error": "not found"}, 404)
    if cur["lifecycle_status"] == "deprecated":
        return JSONResponse({"error": "文档已废弃，无需重复操作"}, 400)
    
    with conn:  # 事务
        conn.execute("""UPDATE documents 
                        SET lifecycle_status='deprecated', deprecated_at=CURRENT_TIMESTAMP,
                            deprecated_by=?, deprecate_reason=?, lifecycle_version=lifecycle_version+1
                        WHERE id=?""", (actor, reason, doc_id))
        conn.execute("UPDATE document_chunks SET lifecycle_status='deprecated' WHERE document_id=?",
                     (doc_id,))
        conn.execute("""INSERT INTO document_lifecycle_log 
                        (document_id, from_status, to_status, operator, reason)
                        VALUES (?, ?, 'deprecated', ?, ?)""",
                     (doc_id, cur["lifecycle_status"], actor, reason))
    audit(actor, "doc_deprecate", f"文档#{doc_id} 软删除: {reason[:80]}", conn=conn)
    return {"ok": True, "doc_id": doc_id, "lifecycle_status": "deprecated"}
```

### 4.3 API 设计：「一键来源追溯」

#### 4.3.1 节点追溯端点

```python
# routers/graph_workspace.py
@router.get("/api/entities/{entity_id}/provenance")
def entity_provenance(entity_id: str, conn=Depends(db_session), user=Depends(current_user)):
    """FR-KG-11：节点数据来源一键追溯（5 段视图）。
    
    返回结构：
    {
      "entity": {...},                    // 节点本体（含元数据）
      "source_document": {...},            // 来源文档 + 当前 lifecycle_status
      "source_chunk": {...},               // 命中的具体切片（含 section / bm25_text）
      "version_chain": [...],              // sysml_versions 版本链路（如果有）
      "audit_trail": [...],                // graph_edit_logs + knowledge_commits 合并
      "deprecated_trace": {...},           // 若已废弃：废弃时间/原因/操作人
      "siblings_from_same_doc": [...]      // 同源文档产出的其他节点（用于关联理解）
    }
    """
    ent = conn.execute("SELECT * FROM entities WHERE id=?", (entity_id,)).fetchone()
    if not ent: return JSONResponse({"error": "entity not found"}, 404)
    
    result = {"entity": dict(ent)}
    
    # 1) 来源文档
    if ent["source_doc"]:
        doc_row = conn.execute("""SELECT d.id, d.filename, d.lifecycle_status, d.uploaded_by, 
                                         d.created_at, d.deprecated_at, d.deprecate_reason,
                                         m.title, m.author, m.version
                                  FROM documents d 
                                  LEFT JOIN doc_metadata m ON m.document_id=d.id
                                  WHERE d.filename=?""", (ent["source_doc"],)).fetchone()
        result["source_document"] = dict(doc_row) if doc_row else None
    
    # 2) 来源切片（按 source_doc + 节点名查找最相关 chunk）
    chunks = conn.execute("""SELECT id, chunk_index, content, section, bm25_text, lifecycle_status
                              FROM document_chunks
                              WHERE document_id IN (
                                  SELECT id FROM documents WHERE filename=?
                              ) AND content LIKE ? LIMIT 3""",
                          (ent["source_doc"], f"%{ent['name']}%")).fetchall()
    result["source_chunk"] = [dict(c) for c in chunks]
    
    # 3) 版本链路
    if ent.get("sysml_version_id"):
        versions = conn.execute("""SELECT id, version, sysml_version, created_by, created_at
                                     FROM sysml_versions WHERE id=? OR sysml_version_id=?
                                     ORDER BY sysml_version""",
                                (ent["sysml_version_id"], ent["sysml_version_id"])).fetchall()
        result["version_chain"] = [dict(v) for v in versions]
    
    # 4) 审计轨迹（graph_edit_logs + knowledge_commits 合并按时间倒序）
    audit = conn.execute("""SELECT 'edit' AS kind, op AS action, operator, payload, created_at
                             FROM graph_edit_logs WHERE node_id=?
                             UNION ALL
                             SELECT 'commit' AS kind, kind AS action, created_by AS operator,
                                    message AS payload, created_at
                             FROM knowledge_commits WHERE changes LIKE ?
                             ORDER BY created_at DESC LIMIT 20""",
                        (entity_id, f'%"{entity_id}"%')).fetchall()
    result["audit_trail"] = [dict(a) for a in audit]
    
    # 5) 废弃轨迹
    if ent["status"] == "deprecated":
        result["deprecated_trace"] = {
            "deprecated_at": ent.get("reviewed_at"),
            "deprecated_by": ent.get("reviewed_by"),
            "current_status": "deprecated",
            "reason": "见关联文档废弃记录",
        }
    
    # 6) 同源文档其他节点（用于关联理解，限制 20 条）
    if ent["source_doc"]:
        siblings = conn.execute("""SELECT id, name, entity_type, status
                                    FROM entities WHERE source_doc=? AND id != ?
                                    ORDER BY created_at DESC LIMIT 20""",
                                (ent["source_doc"], entity_id)).fetchall()
        result["siblings_from_same_doc"] = [dict(s) for s in siblings]
    
    return result
```
