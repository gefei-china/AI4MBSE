### 3.5 元素级时态版本（需求 #4/#8）——**结构性空转** 🔴

实现侧**看起来非常完整**：

```
列：valid_from / valid_to / is_current / tx_from / tx_to     ← 双时态（业务时间 + 事务时间）
索引：idx_ent_valid_current / idx_ent_valid_from / idx_ent_valid_range
视图：v_current_entities / v_temporal_entities
端点：GET /api/knowledge/entities/{eid}/history   → list_entity_history()
      GET /api/knowledge/entities/{eid}/at?as_of= → get_entity_as_of()   ← 时点查询（time travel）
```

**但实测证伪其有效性**：

| 判据 | 实测 | 含义 |
|---|---|---|
| 同 `(id, branch)` 多行组数 | **0** | 主键 `PRIMARY KEY (id, branch)` 保证**每键恒 1 行** → 修改是 `UPDATE` 原地改写，**永不产生历史行** |
| `valid_to` 非空 | **0 / 189** | 无任何"已退役"版本 |
| `is_current` | 189/189 = 1 | 全为当前 |
| `valid_from` 非空 | 128 / 189 | 部分填充，但无配对的 `valid_to` |

→ **`/history` 永远只返回 1 行；`/at?as_of=` 对任意历史时刻都会命中同一当前行。** 这是「**列与端点都在、语义永不生效**」的典型空转。
**根因**：时态建模要求"一实体多版本行"，而主键 `(id, branch)` 只允许一行 —— **两者自相矛盾**。
**修法**（见 §6 P1-1）：主键扩为 `(id, branch, valid_from)`，或改独立历史表 `entity_versions`。

## 5. 行业标杆对比

### 5.1 对标结论矩阵

| 标杆 | 其版本管理核心范式 | 本平台 | 判定 |
|---|---|---|---|
| **Git / GitLab** | 分支 = **指针**（创建零成本）；merge-base **三点式 diff**；PR 状态机（draft/open/merged/closed + reopen）；**分支保护规则可配置**；merge commit **双父指针**；commit **SHA 完整性** | 分支 = **全量物理拷贝**；三点式 diff ✅；状态机 ✅；保护规则**硬编码** ❌；双父 ✅；**无内容哈希** ❌ | **多数已对齐**，差 3 项（保护规则 / SHA / 懒 fork） |
| **Palantir Foundry** | 数据集**事务（transaction）版本** + 分支 + proposal；血缘（lineage） | 提交链 + MR + `knowledge_commits.changes/snapshot`；`entity_merges` + 关系重定向 | **范式同构**，缺 lineage 可视化 |
| **DOORS / Polarion / Jama**（需求管理） | **基线（baseline）** + **suspect link**（变更致链接失效预警）+ 基线间对比报告 | `release` ≈ 基线；**无基线对比报告**；**无 suspect link** ❌ | **缺两类核心能力** |
| **Stardog / TopBraid EDG**（知识图谱） | **bi-temporal**（业务时间 + 事务时间）+ **time travel**；本体 **Git 化 + 语义化版本**；**changeset** 为变更单元 | 时态列/视图/端点齐备但**空转**（§3.5）；本体 SemVer + diff + 兼容性 ✅ | **时态是空转的，本体侧已达标杆** |
| **Neo4j**（图数据库） | 无原生版本，靠 CDC / 应用层 | 应用层分支 + 提交链 | 优于原生 |

### 5.2 三条最值得补的标杆能力

1. **分支保护规则配置化**（Git）—— 现为硬编码，无法按分支配置"必需评审数 / 禁直写 / 禁删"。
2. **基线对比与失效预警**（DOORS/Polarion）—— `release` 已有，缺"v1 vs v2 差异报告"与"上游变更致下游引用失效"的预警。
3. **元素级版本 + 时间旅行**（Stardog/Foundry）—— 骨架已建，**只差主键这一刀**（§3.5）。
