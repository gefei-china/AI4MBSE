### 踩坑（都是"看起来对、实际没生效"那一类）
1. **模块顶层没把 ROOT 加进 sys.path** ⇒ 直接跑脚本时 `from llm import
   llm_client` ModuleNotFoundError（sys.path[0] 是 tools/eval/）。
2. **Edit 工具把字符串行尾单引号吃掉** ⇒ JUDGE_SYSTEM_PROMPT 语法错误。
3. **F8 夹具用 3 条样本测默认 min_compared=10** ⇒ 恒 None 假红（夹具规模
   错不是判据错）；F7/F9 两处预期值也算错（率应是 1/2=0.5；对照失败不计入
   n_failed）——都是夹具错，代码语义正确。
4. **Git Bash 里 taskkill /PID 被 MSYS 路径转换吃掉**（PID 当成路径）⇒ 改用
   PowerShell Stop-Process；`start_server.py --stop` 在 Git Bash 下自身崩
   （netstat stdout 为 None）——**别把工具自带脚本的失败当成"已停止"**。
5. **脱离启动的 server 进程在命令结束后被回收**（DETACHED_PROCESS 也不够，
   会话退出即回收）⇒ 改用受管后台任务（run_in_background）常驻。
6. 本机 http_proxy=127.0.0.1:57668 ⇒ 访问本机服务要 `--noproxy '*'`，
   否则随机 502（"upstream connect failed"）——很容易误判成服务端挂了。
