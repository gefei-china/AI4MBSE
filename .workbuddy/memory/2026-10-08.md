**错误**：v3.0 §0.2 写了「19 个 active Agent 的 `intent_keywords` **全部为 0 条**」，

**这个错误的性质**（值得反复警惕）：
**类型处理错误会伪装成"数据问题"**。我看到"全空"就顺势推出了"能力失效"，

**凡是下「某能力不可用」这类结论前，必须先确认取数方式本身是对的** ——

- ~~「空表导致下沉」~~ →错
